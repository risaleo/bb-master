接客時の確認順

  1. 現在の回線名を確認
  2. 1G / 10Gを確認
  3. 固定電話・TVの利用有無を確認
  4. 番号を残したいか確認
  5. 転用承諾番号 / 事業者変更承諾番号が必要か確認
  6. その組み合わせが移行可能か最新一覧表で確認

注意

「同じ光だからそのまま移れる」と決めつけない。1G→10G、電話・TVオプション、回線種別によって手続きが変わる場合があります。

固定電話・TV

ネットだけ見て決めない

☎ 固定電話

必ず聞く：現在の電話サービス / 電話番号を残したいか / 発番元 / オプション。

番号の引継ぎ可否は条件で変わるため、資料・カスタマーセンターで確認。

▣ TV

必ず聞く：光テレビを使っているか / 地デジだけか / BS・専門チャンネルも必要か。

回線変更でTVの工事や視聴方法が変わる可能性があります。

用語図解

新人さん向けに一言で

1G / 10G

契約上の最大通信速度のプラン区分。10Gは対応エリア・機器・配線条件も確認。

光コラボ

NTTの光回線設備を使い、各事業者が自社サービスとして提供する仕組み。

転用

フレッツ光から光コラボへ移る手続き。

事業者変更

光コラボから別の光コラボへ移る手続き。

ホームルーター

回線工事をせず、モバイル回線を使って家のWi-Fiを作る機器。

独自回線

フレッツ系とは異なる設備・提供方式を使う回線。エリアと工事条件の確認が重要。
